# MusicHive

**Buzzing with music collaborations** – MusicHive is a full-stack platform designed to streamline the hiring, booking, and content-sharing process in the music industry. 
It connects musicians, bands, and event planners through a centralized system, solving real-world problems like last-minute gigs and music monetization.

## 🚀 Basic Features
• Musician, band, and user registration
• Login and dashboard redirection based on user type
• Band and musician profile creation with photo, instrument/event category, and price
• Musician hiring:- request → approval → payment
• Music chords upload, preview, purchase, and review
• Booking management: create, view, edit, delete, cancel
• Filters by instrument type, band category, price, and availability
• Request and notification system
• Future enhancements: AI-based recommendation engine

## 🎯 Purpose & Objectives
• Simplify the process of hiring musicians or booking bands
• Help bands find and book musicians during emergencies
• Enable musicians to share and monetize song chords
• Provide a searchable directory with filtering

## 👥 Target Users

- General users (event planners, fans)
- Individual musicians
- Band owners

## 🛠️ Tech Stack

- Frontend: React
- Backend: Node.js
- Database: MongoDB
- Authentication: JWT / OAuth2
- Others: Stripe for payments, Firebase for notifications.
